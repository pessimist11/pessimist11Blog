我对 AI 的最初印象，来自 2022 年年底发布的 ChatGPT。第一次见识到这样的生成式模型，对我来说，那种冲击不亚于人类第一次见到火。

当时，我还是人工智能专业的大二学生，本能地以为 GPT 不过是一个吸收了大量互联网语料的超级搜索引擎。直到后来不断发布的新模型一次次冲击我的认知，我才开始去了解什么是自然语言处理，什么是 Transformer，什么是生成式模型。

如今，大模型的能力与当初的 GPT-3.5 相比，已经是一个天上、一个地下。百万级上下文窗口基本成了模型的标配，而那时候，给 GPT-3.5 发一篇文章，还得分好几次。

AI 给我的第二次冲击是在 2026 年 5 月。我在 GitHub 上发现了一个轻量化 Agent：nanobot。安装到电脑上后，我才真正感受到 Agent 的魅力：只要给它一个指令，它就能帮我操作电脑、修改文件、生成 PPT、完善项目。

到了现在，各种 Agent 已经百花齐放：Codex、Claude Code、WorkBuddy、dsh 等等。各家大模型公司在基础模型、算力建设和 Agent Harness 上投入重金，新模型基本上每两到三个月就会更新一轮，市场对大模型的热情也依旧不减。Claude Code 背后的 Anthropic，在 [2026 年 5 月 28 日公布的 H 轮融资](https://www.anthropic.com/news/series-h)中，投后估值已经达到 9650 亿美元。

随着 AI 迅猛发展，最先受到影响的行业就是互联网。可以说，一个程序员配合 Claude Code，效率能抵得上十个同等水平的程序员。对我来说，最直观的感受就是 2027 届秋招的 HC 大幅缩减：各大互联网公司都不再公布今年的招聘名额；去年能拿到一大把 offer 的简历，放到今年，可能还是零 offer。

面对不断进步的模型和 Agent，我想，各大厂似乎也没有不降本增效的理由。当然，正是在这样的背景下，一些极其优秀的人才依然可以很轻松地拿到大几百万元的薪酬包，而普通开发岗的竞争则愈发激烈。

互联网还有未来吗？我对此持悲观态度。
