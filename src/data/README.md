# 首页精选照片池

[`home-photos.ts`](home-photos.ts) 是首页照片候选名单，每条记录包含所属相册、源图路径、图片描述和入选理由。首页只从该池中等概率随机选择一张，不回退到全部照片或相册封面。

随机发生在构建时，同一次静态部署中刷新或切页返回展示同一张；开发模式重新请求页面时可能重新选择。

## 更新与筛选

- 每次新增、补充或替换「帧」照片时，维护助手都要查看本次变更的实际图片，主动把适合首页的照片加入名单，无需作者逐次另行要求。没有合适照片时不强行收录，并在反馈中说明。
- 题材不限于风景或花草。人物、背影、生活片段、物品和实验性画面，只要能表达作者的个性、情绪或想法，且尺寸、构图适合首页，也可以入选。
- 综合判断表达力、视觉重心、色调、分辨率和画幅，检查桌面与手机的全屏居中裁切。窄屏不必保留每个边缘细节，但要保留关键主体、人物姿态和表达意图，并考虑底部相册说明的可读性。
- 不按合影、自拍、食物或物品等题材一概排除，也不把暗调、颗粒或动感直接视为缺陷；判断它们是否服务于画面的情绪和想法。普通记录照若缺少适合首页的表达或构图，可以只保留在相册。
- 不以“是横图”作为充分条件，不按文件名或封面列表自动收录，不为凑数量强求各相册入选数相同。

## 记录与校验

- `albumId`：`src/content/zhen/` 中的文章文件名，不含扩展名。
- `path`：相册已引用的稳定 `/gallery/...` 路径，对应 `src/assets/gallery/` 中的现有源图，不复制图片。
- `alt`：准确描述图片内容。
- `reason`：简要说明表达、构图及裁切方面的入选理由。

删除照片或重命名相册时同步更新名单。首页构建检查池非空、图片和所属相册存在、图片被相册引用、横向尺寸及重复路径；名单错误会使构建失败。审美和裁切效果仍需实际看图。
