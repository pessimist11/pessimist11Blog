# Moon textures

Credit: NASA's Scientific Visualization Studio.

Source: [CGI Moon Kit](https://svs.gsfc.nasa.gov/4720/).

- lroc-albedo.webp: 2025 LROC color map, converted from lroc_color_2k.jpg (2048 × 1024) to grayscale WebP.
- lola-height.jpg: original LOLA elevation preview ldem_3_8bit.jpg (1024 × 512).

These maps are used to render the homepage moon. They are for display, not scientific measurement.
